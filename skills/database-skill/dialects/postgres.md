# PostgreSQL Dialect — JSONB, TIMESTAMPTZ, IDENTITY, CONCURRENTLY, RLS

## 🎯 Trigger

Load khi: DB là PostgreSQL, cần biết tính năng riêng (JSONB, CTE, GIN, CONCURRENTLY).

---

## 1. Always

```sql
-- TIMESTAMPTZ cho timestamp (luôn)
created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),

-- JSONB thay vì JSON
preferences JSONB NOT NULL DEFAULT '{}',
```

---

## 2. Supports (PostgreSQL 16+)

| Feature | Notes |
|---|---|
| JSONB + GIN index | **Luôn dùng JSONB**, không JSON |
| `GENERATED AS IDENTITY` | Ưu tiên hơn `SERIAL` |
| `CREATE INDEX CONCURRENTLY` | Build index không block writes — **ngoài transaction** |
| Partial Index | Full support |
| Expression Index | Full support |
| `INCLUDE` (covering index) | Index include extra columns |
| `SKIP LOCKED` / `NOWAIT` | Queue pattern |
| Advisory Lock | Application-level mutex |
| Recursive CTE | Tree traversal |
| Materialized View | Auto-refresh via trigger |
| RLS (Row Level Security) | Multi-tenant an toàn |
| `RETURNING` | Full support |
| `FETCH FIRST N ROWS ONLY` | SQL standard pagination |
| `ROLLBACK` DDL | DDL trong transaction — rollback được |

---

## 3. Not support / Cẩn thận

| Feature | PG behavior |
|---|---|
| `ALTER COLUMN ... AFTER` | Không — column order mặc định |
| `INSERT ... ON DUPLICATE KEY` | Dùng `ON CONFLICT DO UPDATE` |
| `REPLACE INTO` | Không — dùng `INSERT ... ON CONFLICT` |
| Invisible Index | Không — test = CREATE + DROP |
| `GET_LOCK()` | Dùng `pg_advisory_lock()` |

## 4. JSONB — sức mạnh của PostgreSQL

### So sánh JSON vs JSONB

| | JSON | JSONB |
|---|---|---|
| Storage | Giữ nguyên text | Parsed, không whitespace |
| Index | Không | ✔ GIN index |
| Query performance | Chậm | Nhanh |
| Key order | Giữ nguyên | Sắp xếp tự động |

**Luôn dùng JSONB.**

### JSONB queries

```sql
-- Tạo JSONB column
ALTER TABLE users ADD COLUMN preferences JSONB NOT NULL DEFAULT '{}';

-- GIN index
CREATE INDEX idx_users_preferences ON users USING gin (preferences);

-- Query
SELECT * FROM users WHERE preferences @> '{"theme": "dark"}';
SELECT * FROM users WHERE preferences ->> 'language' = 'vi';
SELECT * FROM users WHERE preferences ? 'notifications';
```

## 5. TIMESTAMPTZ — chuẩn vàng timestamp

```sql
-- ✅ ĐÚNG: TIMESTAMPTZ (timestamp with time zone)
created_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
updated_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),

-- ❌ SAI: TIMESTAMP (không timezone) — dễ sai múi giờ
created_at TIMESTAMP NOT NULL DEFAULT NOW(),

-- Query
SELECT * FROM users WHERE created_at >= '2024-06-01T00:00:00Z';
SELECT * FROM users WHERE created_at >= NOW() - INTERVAL '7 days';

-- Chuyển timezone
SELECT created_at AT TIME ZONE 'Asia/Ho_Chi_Minh' FROM users;
```

## 6. GENERATED AS IDENTITY

```sql
-- ✅ ĐÚNG (PostgreSQL 10+): IDENTITY
id INTEGER GENERATED ALWAYS AS IDENTITY PRIMARY KEY,

-- Hoặc GENERATED BY DEFAULT (cho phép insert giá trị)
id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,

-- ❌ SAI (deprecated): SERIAL
id SERIAL PRIMARY KEY,
```

**Ưu điểm IDENTITY so với SERIAL:**
- Tuân thủ SQL standard
- Không tự động tăng sequence khi copy schema
- Có thể set permission riêng

## 7. CREATE INDEX CONCURRENTLY

```sql
-- Tạo index không block writes
-- ⚠️ PHẢI chạy ngoài transaction
CREATE INDEX CONCURRENTLY idx_users_email ON users (email);

-- Trong transaction → lỗi
BEGIN;
CREATE INDEX CONCURRENTLY idx_users_email ON users (email);  -- ❌ LỖI
COMMIT;
```

## 8. CTE và Recursive CTE

### CTE thường

```sql
WITH active_users AS (
    SELECT * FROM users WHERE is_active = true
)
SELECT * FROM active_users WHERE created_at >= '2024-01-01';
```

### Recursive CTE (tree)

```sql
WITH RECURSIVE org_tree AS (
    -- base case
    SELECT id, name, parent_id, 1 AS level
    FROM organizations WHERE id = 1

    UNION ALL

    -- recursive case
    SELECT o.id, o.name, o.parent_id, t.level + 1
    FROM organizations o
    JOIN org_tree t ON o.parent_id = t.id
)
SELECT * FROM org_tree ORDER BY level;
```

**PG 12+:** CTE tự động inline (không materialize) trừ khi có side-effect.

## 9. Materialized View

```sql
-- Tạo
CREATE MATERIALIZED VIEW mv_user_stats AS
SELECT status, COUNT(*) AS cnt FROM users GROUP BY status;

-- Refresh (có thể schedule)
REFRESH MATERIALIZED VIEW mv_user_stats;
REFRESH MATERIALIZED VIEW CONCURRENTLY mv_user_stats;  -- không block read
```

**Concurrent refresh:** cần unique index trên materialized view.

## 10. RLS (Row Level Security)

```sql
-- Bật RLS trên table
ALTER TABLE accounts ENABLE ROW LEVEL SECURITY;

-- Tạo policy: user chỉ thấy account của tenant mình
CREATE POLICY tenant_isolation ON accounts
USING (tenant_id = current_setting('app.tenant_id')::INT);

-- Set context (từ ứng dụng)
SET app.tenant_id = '42';
SELECT * FROM accounts;  -- chỉ thấy tenant 42
```

## 11. Giới thiệu Index types

| Index type | Use case |
|---|---|
| **B-tree** (default) | `=`, `>`, `<`, `BETWEEN`, `LIKE 'prefix%'` |
| **GIN** | JSONB, array, full-text search |
| **GiST** | Full-text, geometry, range types |
| **BRIN** | Table lớn, chronologically ordered data (logs, timestamps) |
| **Hash** | `=` equality, hiếm khi cần |

```sql
CREATE INDEX idx_logs_created_at ON logs USING brin (created_at);
-- BRIN: vài KB index thay vì vài GB B-tree cho table 1B rows
```

## 12. Anti-patterns

| Anti-pattern | Vấn đề | Fix |
|---|---|---|
| Dùng JSON thay JSONB | Chậm hơn JSONB | `JSONB` |
| Dùng `TIMESTAMP` thay `TIMESTAMPTZ` | Sai múi giờ | `TIMESTAMPTZ` |
| Dùng `SERIAL` thay `IDENTITY` | Deprecated, không chuẩn | `GENERATED AS IDENTITY` |
| `CREATE INDEX` trong transaction | Block writes | `CREATE INDEX CONCURRENTLY` ngoài transaction |
| Không index JSONB queries | Seq Scan trên JSONB | GIN index |
| Dùng OFFSET cho pagination lớn | Chậm dần | Cursor / Keyset pagination |
